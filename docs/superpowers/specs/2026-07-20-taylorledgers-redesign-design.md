# TaylorLedgers.com Homepage Redesign

## Context

Unrelated to this repo's turtle-mining codebase — a one-off request to improve the
homepage of the user's live Wix site, https://www.taylorledger.com (bookkeeping
business, site name "Taylorledger" in Wix). Work is done live in the Wix editor via
the Claude in Chrome browser tool, using the user's existing logged-in Wix session.
No code is produced; the "implementation" is direct manipulation of the Wix editor.

Reference sites used for inspiration (not to be copied verbatim — messaging patterns
and structure only):
- https://cocountant.com/services/bookkeeping-services/ — polished, corporate
  "controller-led" positioning; problem→solution framing; 3-step onboarding; strong
  trust-building and closing CTA.
- https://www.raberiservices.com/accounting-and-bookkeeping/buena-park-ca —
  simpler local-firm site; credential-forward, plain and direct.

## Constraints (explicit user instructions)

- Keep all existing colors (cream/beige background, black accent blocks, green
  "Book Now" pill buttons).
- Keep all existing images (portrait photo, abstract-art service icons). Images may
  be rearranged but never deleted.
- Never click Publish without the user's explicit go-ahead each time.
- User has given latitude to add general polish beyond the specific list below
  ("feel free to add anything to make my website look better").

## Current Homepage Structure (as of this writing)

1. Header — "TaylorLedgers™" wordmark, hamburger menu, "Contact Us" link.
2. Hero — headline "Stress-Free Bookkeeping Tailored for Small Business Owners",
   subhead, "Learn More" button, portrait photo.
3. "Our Story" — black background section, "Get to Know Us" label.
4. Testimonials — 3 client quotes (Samaria Friends, Britney Bell, Faith Taylor).
5. Services — 3 cards (Free Consultation Call, Bookkeeping Monthly, Financial
   Statement Preparation), each with an abstract-art icon image and a "Book Now"
   button.
6. FAQ — "Why Choose Us?", "How to Get Started", "Do You Offer Custom Packages?"
7. Contact — "Contact Us" heading, phone/email, newsletter signup form, footer
   legal links, Instagram icon.

## Approved Design

Restructure and extend the existing one-page layout — same visual language
throughout (cream background, black accent blocks, serif headline font, green pill
CTAs) — in this order:

1. **Hero** — unchanged content, plus a new thin trust strip beneath it (years in
   business / QuickBooks expertise / client count — text TBD from user, generic
   placeholder until supplied).
2. **New: Problem → Solution section** — short block naming small-business pain
   points (messy books, tax-time stress, unclear cash flow) before introducing
   TaylorLedgers as the fix. Placed before "Our Story."
3. **Our Story** — unchanged.
4. **New: "How It Works" 3-step strip** — promotes the existing "How to Get
   Started" FAQ answer into its own visual section (Book a call → Get set up →
   Monthly reporting), placed before Services.
5. **Services** — same 3 cards/photos/buttons, plus a short "what's included"
   bullet list added under each card's existing description.
6. **Testimonials** — unchanged content, given more visual weight (larger
   type/spacing, no new copy).
7. **FAQ** — trimmed to the 3-4 strongest questions (the "How to Get Started"
   question is removed here since it now has its own section above).
8. **New: closing CTA band** — "Ready for stress-free books?" banner with a
   Book Now button, placed immediately before the footer.
9. **Contact/footer** — unchanged.

Additionally, the user has authorized general polish (spacing, alignment, visual
consistency) beyond this list, as long as colors/images/content meaning are
preserved and nothing is deleted.

## Process / Safety

- All changes are staged in the Wix editor (autosaved as drafts) and reviewed with
  the user before Publish is clicked.
- No account settings, payment info, or credentials are touched.
- Existing contact info (phone, email, Instagram) is preserved exactly.

## Out of Scope

- Pricing page/pricing display (none of the 3 reference sites showed pricing
  either; current site doesn't have it).
- New photography or replacing any existing image.
- Multi-page restructuring — this stays a single homepage, matching the current
  site's structure.
